# Edukacja muzyczna i śpiew w szkole podstawowej — pakiet materiałów

Kompletny zestaw dla osoby rozpoczynającej prowadzenie zajęć śpiewu i muzyki
w polskiej szkole podstawowej. Materiały zgodne z podstawą programową
(Rozporządzenie MEN z 14 lutego 2017 r., **Dz.U. 2017 poz. 356**).

## Zawartość pakietu

| Plik | Opis |
|---|---|
| `Raport-podstawa-programowa-muzyka.docx` (i `.md`) | Raport: oficjalne wymagania, cele kształcenia, treści nauczania, podstawa prawna, ocenianie, źródła. |
| `scenariusze/Scenariusze-lekcji.docx` (i `.md`) | Gotowe scenariusze lekcji dla klas 1–3, 4–7 oraz chóru/koła wokalnego. |
| `materialy/Repertuar-i-materialy.docx` (i `.md`) | Repertuar (patriotyczny i dziecięcy), rozśpiewki, ćwiczenia rytmiczne, instrumentarium, źródła nut i podkładów. |
| `prezentacja/Prezentacja-edukacja-muzyczna.pptx` | Prezentacja dla dyrekcji/rady pedagogicznej (edytowalna). |
| `prezentacja/Prezentacja-edukacja-muzyczna.pdf` | Ta sama prezentacja w formacie PDF (do wyświetlenia/druku). |

## Zakres

- **Klasy 1–3** – edukacja muzyczna w ramach edukacji wczesnoszkolnej.
- **Klasy 4–7** – przedmiot „Muzyka” (1 godz./tydzień).
- **Chór / koło wokalne** – zajęcia dodatkowe (rozwijające).

## Jak korzystać

1. Zacznij od **Raportu** – rozumiesz, czego wymaga prawo i jak zbudować program.
2. **Scenariusze** – gotowe do przeprowadzenia lekcje (do adaptacji).
3. **Repertuar i materiały** – co śpiewać i grać oraz skąd wziąć nuty/podkłady.
4. **Prezentacja** – przedstaw program dyrekcji i radzie pedagogicznej.

> Pliki źródłowe `.md` służą do łatwej edycji; wersje `.docx`/`.pptx`/`.pdf`
> są gotowe do wydruku i prezentacji.
